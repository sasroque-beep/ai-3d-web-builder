# Design

> Status: **planned** — scaffolding only, no code yet.

## Responsibility

Define page architecture (section order, hierarchy) and apply the design
system to produce a layout specification for `site-builder`.

## Belongs here

- Page/section blueprints
- Design-token application and theming decisions
- Accessibility and responsiveness rules at the layout level

## Does NOT belong here

- Reusable presentational components (`src/ui`)
- 3D/motion scenes (`../experience-3d`)
- Copy text (`../copy`)

## Depends on

- `src/lib`, `src/ui`, `src/ai`

See [`src/README.md`](../../README.md) for dependency rules.
