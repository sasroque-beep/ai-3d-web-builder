# 🎨 Design System — AI 3D Web Builder

## Visão Geral

Este documento define os princípios visuais e de experiência do usuário do AI 3D Web Builder.

O sistema deve criar interfaces modernas, claras, responsivas e orientadas à conversão.

Toda interface deve considerar:

- Clareza
- Hierarquia visual
- Feedback
- Performance
- Acessibilidade
- Estados de carregamento
- Animações
- Responsividade

---

# 1. Princípio Principal

Toda interface deve comunicar claramente:

- Onde o usuário está
- O que está acontecendo
- O que pode ser feito
- O que acontecerá depois de uma ação

O usuário nunca deve ficar sem feedback após realizar uma ação.
